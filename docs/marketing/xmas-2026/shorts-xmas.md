# 크리스마스 쇼츠·릴스 대본 3편 (2026-11-21)

세로 15~25초. 인스타 릴스·유튜브 쇼츠·스레드 영상에 같은 영상을 올려요. 링크는 프로필에: `https://remember-you.watalabs.com/get?from=share_insta` (채널별 링크는 `../links.md`).
말투는 해요체, 과장 없이. 선물 링크가 쿠팡 파트너스 링크라는 건 영상에는 안 나오니(앱 안에 대가성 문구가 있어요) 따로 적을 필요는 없어요.

**녹화 방법:** 개발 서버 데모 계정으로 화면 녹화(운영의 '데모로 둘러보기'는 닫혔어요). 사진·영상에 나오는 이름은 샘플 이름이에요.

---

## 1편. "아무거나"의 정답 (물어보기)

- **첫 2초(말머리):** 카톡 화면 — "엄마 크리스마스 선물 뭐 갖고 싶어?" / "아무거나~" 자막: **"아무거나"의 진짜 뜻**
- **화면 녹화 ① (3~8초):** 기억해유 사람 화면 → '물어보기' → 링크 보내기. 자막: 링크 하나만 보내요
- **화면 녹화 ② (8~13초):** 받은 사람 화면(앱 없이 웹) — '맞아요'만 누르는 장면. 자막: 아는 건 미리 적어 보내서 '맞아요'만 누르면 돼요
- **화면 녹화 ③ (13~19초):** 엄마 기록에 답이 들어온 장면. 자막: 답장은 내 기록에 바로 들어와요
- **끝(19~22초):** 선물 고르기 화면. 자막: 이제 이걸 보고 고르면 돼요 → **프로필 링크**
- **내레이션(해요체):** "'아무거나'라고 하셔도 괜찮아요. 링크 하나만 보내면, 앱이 없어도 답할 수 있어요. 답은 제 기록에 들어오고, 선물은 그걸 보고 고르면 돼요."
- **캡션:** 엄마한테 뭘 사 드릴지 모르겠을 때, 물어보는 법 바꿔 봤어요 #크리스마스선물 #부모님선물 #선물추천 #기억해유

## 2편. 이 질문 3개, 바로 답해져요? (퀴즈형)

- **첫 2초:** 자막: **여자친구(남자친구)가 못 먹는 음식, 기억나요?**
- **2~12초:** 질문 3개가 차례로 뜨고 매번 3초 멈춤 — ① 못 먹는 음식 ② 신발 사이즈 ③ 음력/양력 생일
- **12~18초:** 기억해유에서 한 사람의 기록 화면을 스크롤(알레르기·사이즈·기념일이 들어 있는 모습). 자막: 들은 건 그때그때 적어 두면 돼요
- **끝:** 자막: 선물 고르기 전에 한 번 보면 돼요 → **프로필 링크**
- **내레이션:** "못 먹는 음식, 신발 사이즈, 음력 생일. 분명 들은 적 있는데 필요할 땐 기억이 안 나죠. 그때그때 적어 두면 선물 고를 때 한 번에 볼 수 있어요."
- **캡션:** 들었는데 기억 안 나는 것들, 적어 두는 앱이에요 #커플선물 #크리스마스선물 #기념일 #기억해유

## 3편. 가격대별로 한 번에 (보여 주기만 하는 15초)

- **첫 2초:** 자막: **예산이 3만원이면?**
- **2~12초:** 선물 고르기 화면에서 가격대 탭(1만원대 → 3만원대 → 5만원대 → 10만원 이상)을 차례로 누르며 목록이 바뀌는 모습. 탭마다 자막: 1만원대 / 3만원대 / 5만원대 / 10만원 이상
- **12~15초:** 자막: 적어 둔 취향을 보고 골라 줘요 → **프로필 링크**
- **내레이션 없이** 음악만(조용한 캐럴 풍). 말 없는 영상이 끝까지 보이는 경우가 많아요.
- **캡션:** 예산부터 정하면 선물 고르기가 쉬워져요 #선물추천 #크리스마스선물추천 #가격대별선물 #기억해유

## 올리는 순서·점검

1. 첫 편은 2편(퀴즈형)이 가장 공유되기 쉬워요. 3편은 보여 주기만 해서 만들기 가장 쉬워요.
2. 올린 뒤 각 채널 링크로 들어온 방문이 관리자 통계 > 유입에 찍히는지 하루 뒤 확인하세요.
3. 댓글 질문(어떤 앱이에요 등)에는 App Store 링크와 "안드로이드는 웹에서 먼저 써 볼 수 있고 앱은 준비 중이에요"를 그대로 답하세요.
4. 반응을 보고 한 주 뒤 같은 형식으로 설 편(명절 선물, 부모님)을 이어 가요.
